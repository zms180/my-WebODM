## 部署架构

GeoModel 系统由以下组件组成：

```
┌─────────────────────────────────────────────────┐
│              GeoModel 系统架构                   │
├─────────────────────────────────────────────────┤
│                                                 │
│  ┌─────────────┐         ┌──────────────┐      │
│  │   webapp    │────────▶│   broker     │      │
│  │  (Django)   │         │   (Redis)    │      │
│  └─────────────┘         └──────────────┘      │
│         │                                       │
│         ▼                                       │
│  ┌─────────────┐         ┌──────────────┐      │
│  │   worker    │────────▶│      db      │      │
│  │  (Celery)   │         │ (PostgreSQL) │      │
│  └─────────────┘         └──────────────┘      │
│         │                                       │
│         ▼                                       │
│  ┌─────────────┐                               │
│  │ node-odx-1  │                               │
│  │  (NodeODX)  │                               │
│  └─────────────┘                               │
│                                                 │
└─────────────────────────────────────────────────┘
```

**镜像列表**：

- `geomodel_webapp:v1.0` - Web 应用和 Worker（基于 webodm/webodm_webapp）
- `geomodel_db:v1.0` - 数据库（基于 webodm/webodm_db）
- `geomodel_nodeodx:v1.0` - 处理节点（基于 webodm/nodeodx:gpu）
- `geomodel_api:v1.0` - API 网关服务（包含 OSGB 转换工具）
- `redis:7.0.10` - 消息代理（官方镜像）

## 构建镜像

**重要说明**：所有镜像都使用 `--platform linux/amd64` 参数构建 Linux 版本，确保在服务器上正常运行。

### 1. 构建 webapp 镜像

```bash
# 在项目根目录执行
docker build \
  --platform linux/amd64 \
  --pull=false \
  -t geomodel_webapp:v1.0 \
  -f local-deploy/Dockerfile.webapp \
  .

# 构建说明：
# --platform linux/amd64  确保构建 Linux amd64 架构镜像（服务器部署必需）
# --pull=false            不重新拉取基础镜像，使用本地现有镜像
# -t geomodel_webapp:v1.0 镜像名称和标签
# -f local-deploy/Dockerfile.webapp  指定 Dockerfile 文件
```

### 2. 构建 nodeodx 镜像

```bash
docker build \
  --platform linux/amd64 \
  --pull=false \
  -t geomodel_nodeodx:v1.0 \
  -f local-deploy/Dockerfile.nodeodx \
  .
```

### 3. 构建 geomodel-api 镜像（可选，启用 API 功能需要）

```bash
# 构建 GeoModel API 镜像，包含：
# - FastAPI 服务
# - RabbitMQ 工作流
# - OSGB 转换工具（tileset_to_osgb, verify_osgb）
# - 1985 高程转换支持

docker build --platform linux/amd64 --pull=false -t geomodel_api:v1.0 -f local-deploy/Dockerfile.geomodel-api .


docker build \
  --platform linux/amd64 \
  --pull=false \
  --build-arg HTTP_PROXY=http://192.168.18.7:10808 \
  --build-arg HTTPS_PROXY=http://192.168.18.7:10808 \
  -t geomodel_api:v1.0 \
  -f local-deploy/Dockerfile.geomodel-api .


# 注意：此镜像构建时间较长（约 10-20 分钟），因为需要：
# 1. 安装系统依赖（CMake, OpenSceneGraph, Assimp）
# 2. 编译 OSGB 转换工具
# 3. 安装 Python 依赖（FastAPI, Rasterio 等）
```

### 4. 重命名 db 镜像

```bash
# 不需要构建，直接重命名现有镜像
docker tag webodm/webodm_db:latest geomodel_db:v1.0
```

### 5. 验证镜像

```bash
docker images | grep -E "(geomodel|redis)"

# 应该看到：
# geomodel_webapp        v1.0    xxx123    Just now    2.5GB
# geomodel_nodeodx       v1.0    yyy456    Just now    4.0GB
# geomodel_api          v1.0    zzz789    Just now    1.2GB
# geomodel_db            v1.0    aaa111    Just now    300MB
# redis                  7.0.10  bbb222    1 week ago  117MB
```

## 导出镜像

### 1. 导出核心镜像（不含 API）

```bash
# 导出 WebODM 核心服务镜像
docker save \
  geomodel_webapp:v1.0 \
  geomodel_db:v1.0 \
  geomodel_nodeodx:v1.0 \
  redis:7.0.10 \
  -o geomodel-images.tar

# 文件大小约 6-7 GB
```

### 2. 导出完整镜像（包含 API）

```bash
# 导出所有镜像，包括 GeoModel API
docker save \
  geomodel_webapp:v1.0 \
  geomodel_db:v1.0 \
  geomodel_nodeodx:v1.0 \
  geomodel_api:v1.0 \
  redis:7.0.10 \
  -o geomodel-images-full.tar

# 文件大小约 8-9 GB
```

### 3. 查看导出文件

```bash
ls -lh geomodel-images*.tar

# 示例输出：
# -rw-r--r-- 1 user user 6.8G Aug 28 16:00 geomodel-images.tar
# -rw-r--r-- 1 user user 8.5G Aug 28 16:10 geomodel-images-full.tar
```

## 客户服务器部署

### 1. 上传镜像文件到服务器

```bash
# 使用 scp 或其他方式上传到服务器
scp geomodel-images-full.tar user@server:/home/top/WebODM/

# 或使用 U 盘等物理介质拷贝
```

### 2. 导入镜像

```bash
# 进入部署目录
cd /home/top/WebODM/local-deploy

# 导入 Docker 镜像（需要几分钟，取决于文件大小）
docker load -i ../geomodel-images-full.tar

# 验证导入成功
docker images | grep -E "(geomodel|redis)"

# 应该看到：
# geomodel_webapp        v1.0    xxx123    ...    2.5GB
# geomodel_nodeodx       v1.0    yyy456    ...    4.0GB
# geomodel_api          v1.0    zzz789    ...    1.2GB
# geomodel_db            v1.0    aaa111    ...    300MB
# redis                  7.0.10  bbb222    ...    117MB
```

### 3. 配置环境变量

```bash
# 编辑 .env 文件
vi .env

# 修改以下配置：
WO_HOST=192.168.1.100        # 服务器 IP 地址
WO_PORT=8001                 # WebODM 端口
WO_MEDIA_DIR=/home/top/WebODM/data  # 数据存储路径

# GeoModel API 配置（如果启用）
GEOMODEL_API_PORT=8889
GEOMODEL_API_ENV=prod          # 生产环境
WEBODM_USERNAME=admin
WEBODM_PASSWORD=your-password  # 修改为安全密码
GEOMODEL_API_KEY=your-api-key    # 修改为随机密钥
GEOMODEL_API_WEBHOOK_SECRET=your-webhook-secret  # 修改为随机密钥
```

### 4. 启动服务

#### 方式 1：只启动 WebODM 核心服务

```bash
./geomodel.sh start \
  --media-dir /home/top/WebODM/data \
  --port 8001 \
  --node-memory 30g \
  --gpu \
  --detached
```

#### 方式 2：启动 WebODM + API 服务

```bash
./geomodel.sh start \
  --media-dir /home/top/WebODM/data \
  --port 8001 \
  --node-memory 30g \
  --gpu \
  --with-api \
  --detached
```

**参数说明**：

- `--media-dir`: 数据存储路径
- `--port`: WebODM 端口
- `--node-memory`: 处理节点内存限制
- `--gpu`: 启用 GPU 加速
- `--with-api`: 启动 GeoModel API 服务（可选）
- `--detached`: 后台运行

### 5. 验证服务状态

```bash
# 查看服务状态
./geomodel.sh status

# 或使用 docker 命令
docker ps

# 应该看到运行中的容器：
# - db (PostgreSQL)
# - broker (Redis)
# - webapp (WebODM)
# - worker (Celery)
# - node-odx-1 (GPU 处理节点)
# - geomodel-api (如果使用 --with-api)
```

### 6. 测试访问

```bash
# 测试 WebODM
curl http://192.168.1.100:8001/

# 测试 GeoModel API（如果启用）
curl http://192.168.1.100:8889/healthz

# 在浏览器中访问：
# WebODM UI: http://192.168.1.100:8001
# API 文档: http://192.168.1.100:8889/docs
```

### 7. 创建管理员账户

```bash
# 进入 webapp 容器
docker exec -it webapp bash

# 创建管理员用户
python manage.py createsuperuser

# 按提示输入：
# Username: admin
# Email: admin@example.com
# Password: ********

# 退出容器
exit
```

### 8. 配置 WebODM Webhook（如果启用 API）

```bash
# 进入 webapp 容器
docker exec -it webapp bash

# 编辑配置文件
vi /webodm/webodm/settings.py

# 在文件末尾添加：
WEBHOOK_ENABLED = True
WEBHOOK_URL = "http://geomodel-api:8889/webodm/task-completed"
WEBHOOK_SECRET = "your-webhook-secret"  # 与 .env 中的 GEOMODEL_API_WEBHOOK_SECRET 一致

# 保存并退出
exit

# 重启 webapp 服务
docker restart webapp
```
